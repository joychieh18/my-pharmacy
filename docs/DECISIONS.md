# 實作決策

- 以 React 狀態保存個人遊戲。代碼進貨的非同步工作由 AbortController 以及目前請求識別共同管控。管理端另用 IndexedDB，個人流程不觸及草稿。
- 圖片以 WebP 品質 0.87 處理，瀏覽器若不支援編碼則採 Canvas 預設 PNG。資料 URL 可隨快照嵌入。管理端移除草稿引用時不清除已發布的實體資產。
- 教材發布包採 ZIP，版本以 UUID 識別，代碼仍完全手動輸入。Git 歷史檢查防止同名版本覆寫，索引狀態可更新。
- 透過配置 A 的原創程序化幾何呈現藥局。介面保留位置及格位按鈕，供鍵盤與 WebGL 無法取得時操作。相機、光源及材質參數仍待人工美術驗收。
- 以目前 Codex `work` 分支開發。正式需求原文附件保存在補充指令檔，對話補交的原始 v22 整理成可查閱的需求文件。

## v23

- 包裝固定為盒 13.5×22.5×7.5 cm、瓶直徑 12 cm／高 18 cm、袋 15×21×3 cm。格位側界扣 1 cm；外側另保留完整 3 cm 支柱寬與 1 cm 間隙。前後各留 1 cm，RX 後方另扣 1 cm 背板。包裝間距 1 cm；單層直立、正面一致，每排在淨寬內置中，前排靠前。
- 盒袋正面採等尺寸貼圖；藥瓶採與 48 段瓶身對齊的 16 段、120° 正面圓弧標籤（瓶身高度的 84%）。共面標籤用多邊形深度偏移，其他表面白色。無圖使用白底、色帶、依字寬換行的粗體學名和獨立劑量。
- 自動配色以學名、劑量、劑型的正規化鍵計算 32-bit FNV-1a 型雜湊。九款色票為藍、青、綠、紫、橘、珊瑚紅、芥末黃、深藍、灰藍。上傳圖片優先，移除後恢復原選擇。
- 總覽標籤 512 px、DPR 上限 1.5；獨立架標籤最高 2048 px、DPR 上限 2。sRGB、三線性 mipmap、線性放大，異向性過濾在硬體支援範圍分別上限 4／8。圖片編碼 WebP 品質優先 0.91，必要時降至 0.82 或 0.70；Canvas 不支援時仍檢查輸出容量。
- 近景每格本體和標籤各一次實例繪製，總覽將同品項跨格跨架合併成同一批實例並保留點擊對應。固定環境的陰影貼圖只在架位構造更動時更新。不為重複包裝複製貼圖。相同貼圖按內容、範本和畫質做引用計數，最後一個使用者卸載後延至當次切換結束釋放。不為每次指標更新重建裁切預覽的貼圖物件。
- 獨立架相機距離 0.48–5 m，觀看目標平移約 x ±0.51 m、y 0.23–1.59 m，保留正面限角。總覽相機維持原視角。近裁切 0.025 m。

# 架構與場景參數

- `src/model.ts` 定義目錄、固定劑型、包裝、位置、格位以及不可變的目錄和擺放更新。遊戲根元件持有記憶體中資料，管理入口有獨立 React 根節點與 IndexedDB。
- 遊戲和管理端使用相同的藥品表單和包裝預覽。`src/images.ts` 驗證圖片、等比縮小並保存正規化裁切參數。3D 使用 CanvasTexture，貼圖依使用量管理，最後一個引用移除後釋放。
- `src/teaching.ts` 定義 schema 與靜態讀取。`scripts/check-teaching.ts` 驗證索引、版本、圖片解碼、相對路徑與 Git 歷史。可讀取的 JSON Schema 在 `docs/schema/`。
- 成果使用同一個 Pharmacy 檢視元件，由 IIFE 與 CSS 內嵌在 HTML 中。資料從單一 application/json script 讀取，序列化會轉義 HTML 特殊字元。匯出會刪去未上架藥品以及架上不需展示的欄位。
- Vite 使用實體雙入口 `index.html` 與 `admin/index.html`。封面、教材、手冊及成果模板均走 Vite BASE_URL。

## v23 包裝渲染及資料相容性

- `src/display.ts` 只讀格位、藥架構造與模板尺寸，輸出可重建的包裝位置。每格資料仍是一個藥品 ID。遊戲與 HTML 使用相同場景，不逐件序列化。
- `src/packaging.tsx` 近景每格、總覽每個品項以實例矩陣共用本體及標籤幾何。相同模板共用幾何，配色、圖片與裁切相同的標籤按畫質層級共用 CanvasTexture。預覽拖曳以同一張貼圖逐幀更新。
- `src/crop-editor.tsx` 的 2D 預覽與 3D 貼圖使用同一裁切座標運算及實際標籤長寬比。新圖片採填滿，既有明確設定照原資料，缺少設定的舊圖片採完整顯示。
- 教材保留 Schema 1 及舊 IndexedDB。新增選填的 `palette` 固定字串 ID，缺省由原三欄重複鍵雜湊分配。圖片、上傳、ZIP、讀取與 CI 共用 5,000,000 bytes 及 2048 px 上限。新版讀取舊教材；v22 驗證器無法讀取帶新版色票或超出舊上限的教材，使用 v23 發布與讀取這些新內容。

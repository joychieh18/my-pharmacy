# My Pharmacy v24 第一階段 UI／UX

| 編號 | 規格 |
|---|---|
| 01 | 獨立藥架下方十個格位只顯示編號與藥品名稱，隨資料即時更新。上架、資訊、替換和丟棄從 3D 格位操作。 |
| 02 | 教材代碼維持六位 ASCII 英數混合且至少各一字，不分大小寫，允許 O、0、I、1。已發布代碼（含停用）保留占用。教師、學生、Schema 與發布驗證共用規則。 |
| 03 | 獨立藥架選藥區固定高度，藥品清單獨立捲動；搜尋與分類控件留在清單上方。提供全部、RX、OTC、未分類、結果數目及選取提示。上架保留搜尋和篩選，替換沿用同一清單。 |
| 04 | 學生頁首以左箭頭及「返回首頁」取代帶加號的返回控制。 |
| 05 | 重新開始入口移到首頁右上角，確認後清除本次學生進度。教師草稿及正式教材維持原狀。 |
| 06 | 首頁主入口旁顯示「先進貨，再開始上架吧！」及「先到『管理藥品』新增或匯入藥品，再進入藥局開始擺放。」 |
| 07 | 首頁右上角的遊戲說明涵蓋進貨、上架、查看、下載及重新整理造成的進度消失。 |
| 08 | 桌面由左至右、手機由上至下，先「我要管理藥品」，再「進入我的藥局」，保留各自的目的地。 |
| 09 | 3D 總覽與獨立藥架右上角提供「3D 藥局操作說明」，含選架、選藥、上架、查看／替換／丟棄、視角與 HTML 下載。空目錄顯示進貨提醒。 |

首頁及 3D 問號使用相同樣式與「遊戲說明」可存取名稱。說明採原生模態視窗，支援 X、Esc 及遮罩，開啟移入焦點、隔離背景輸入，關閉復原焦點；內容過長時僅捲動視窗。開關視窗不修改當前遊戲、選藥或相機。

開發基準為已合併 v23 的最新 `main`。保留 v23 模型、圖片、教材歷史與 GitHub Pages 設定。

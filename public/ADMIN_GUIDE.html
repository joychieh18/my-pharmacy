1. 安裝開發環境

目的　完成「安裝開發環境」。

事前準備　電腦和終端機

操作位置　終端機

成功判準　看到工具版本，npm ci 正常結束。

常見問題與處理　若終端機找不到指令，重開終端機並確認安裝路徑。

2. 本機啟動

目的　完成「本機啟動」。

事前準備　完成 npm ci

操作位置　終端機 / 網站首頁

成功判準　首頁載入封面，進入總覽可見 OTC-01 和 OTC-02。

常見問題與處理　若埠被占用，使用終端機新顯示的埠。

3. GitHub 儲存庫

目的　完成「GitHub 儲存庫」。

事前準備　GitHub 帳號

操作位置　GitHub 的 Code 頁籤

成功判準　git remote -v 顯示你要操作的儲存庫。

常見問題與處理　若資料夾已有下載的 checkout，直接進入它，避免重複複製。

4. 設定 GitHub Pages

目的　完成「設定 GitHub Pages」。

事前準備　具有儲存庫設定權限

操作位置　GitHub → Settings → Pages

成功判準　部署成功後可開首頁與 /my-pharmacy/admin/。

常見問題與處理　若網站 404，先查部署工作是否成功，以及網址是否含 /my-pharmacy/。正式部署待遠端驗證。

5. 查看 GitHub Actions

目的　完成「查看 GitHub Actions」。

事前準備　GitHub 儲存庫已接收程式分支

操作位置　GitHub → Actions

成功判準　驗證、打包、部署皆顯示成功。

常見問題與處理　如果流程尚未列出，確認工作流程檔已進入預設分支。遠端執行待驗證。

6. 更新遊戲網站

目的　完成「更新遊戲網站」。

事前準備　GitHub 寫入權限及已開通 Pages

操作位置　本機終端機 / GitHub Pull requests

成功判準　部署紀錄對應這次合併，重新載入可見更新。

常見問題與處理　若看到舊介面，確認最新部署的 Git SHA 再重整。遠端流程待驗證。

7. 開啟教材管理端

目的　完成「開啟教材管理端」。

事前準備　已啟動本機網站或已部署網站

操作位置　網址列 /my-pharmacy/admin/

成功判準　頁首顯示「教材管理」。

常見問題與處理　換分頁網址、埠號或瀏覽器後可能看不到原草稿，請回到原環境。

8. 新增教材藥品

目的　完成「新增教材藥品」。

事前準備　準備核實過的學名、劑量及劑型

操作位置　教材管理 → 教材藥品

成功判準　在教材藥品清單搜尋到品項。

常見問題與處理　若重複，核對學名、劑量與劑型，並使用既有資料。

9. 圖片與包裝

目的　完成「圖片與包裝」。

事前準備　備妥有授權、2 MB 內的 PNG、JPEG 或 WebP

操作位置　藥品表單 → 正面包裝圖片／3D 包裝預覽

成功判準　圖片保持比例，模板尺寸依固定常數。

常見問題與處理　圖片無法解碼時重新輸出有效圖檔。無圖會顯示白色文字包裝。

10. 建立主題

目的　完成「建立主題」。

事前準備　教材藥品清單至少有一項

操作位置　教材管理 → 主題教材

成功判準　重整後可按同名草稿繼續編輯。

常見問題與處理　若少了某品項，先回教材藥品確認已保存。

11. 手動指定主題代碼

目的　完成「手動指定主題代碼」。

事前準備　準備一個未使用的代碼

操作位置　主題教材 → 主題代碼

成功判準　草稿以大寫保存，匯出時沒有碰撞警告。

常見問題與處理　若代碼已占用，為這個版本另選一組。停用碼也會保留占用。

12. 匯出教材發布包

目的　完成「匯出教材發布包」。

事前準備　已勾選藥品且有正常可讀的索引

操作位置　主題教材 → 驗證並匯出發布包

成功判準　得到 my-pharmacy-teaching.zip，圖檔在 teaching/images。

常見問題與處理　索引讀取失敗時先確認網站路徑與連線。

13. 提交教材

目的　完成「提交教材」。

事前準備　已解壓 ZIP，具 GitHub 寫入權限

操作位置　本機儲存庫 public/teaching

成功判準　差異只增加新教材與索引項，驗證成功。

常見問題與處理　若有多份發布包，逐件依最新索引匯出和合併。遠端提交待驗證。

14. 驗證教材發布

目的　完成「驗證教材發布」。

事前準備　確認 main 部署成功

操作位置　遊戲 → 代碼進貨

成功判準　找到新藥且未自動上架。

常見問題與處理　若找不到代碼，查 GitHub Actions、索引與版本路徑。正式部署待驗證。

15. 停用舊代碼

目的　完成「停用舊代碼」。

事前準備　目標代碼已發布

操作位置　教材管理 → 已發布代碼

成功判準　遊戲提示代碼已停用，舊教材檔案仍保留。

常見問題與處理　若索引變更提示過期，重載後再匯出。正式部署待驗證。

16. 重新啟用舊代碼

目的　完成「重新啟用舊代碼」。

事前準備　代碼目前為停用狀態

操作位置　教材管理 → 已發布代碼

成功判準　代碼恢復，開啟原版本。

常見問題與處理　若改指新版本，還原未發布的索引變更。正式部署待驗證。

17. 建立新教材版本

目的　完成「建立新教材版本」。

事前準備　原教材已發布，備妥新代碼

操作位置　教材管理 → 主題教材

成功判準　索引含獨立新舊版本，舊路徑仍可查詢。

常見問題與處理　若沿用舊碼會撞碼，換新碼後再匯出。正式部署待驗證。

18. 學生代碼進貨

目的　完成「學生代碼進貨」。

事前準備　教師提供有效代碼

操作位置　首頁 → 我要管理藥品 → 從已知的代碼進貨

成功判準　新品加入目錄，重複品項跳過。

常見問題與處理　代碼停用或資源錯誤時，聯絡教師確認部署。

19. 個人藥品管理

目的　完成「個人藥品管理」。

事前準備　備妥核實過的資料

操作位置　首頁 → 我要管理藥品

成功判準　新藥出現在目錄；刪除品項後相應格位會清空。

常見問題與處理　若 500 MG 與 500mg 撞鍵，使用原品項或核對實際規格。

20. 配置 3D 藥架

目的　完成「配置 3D 藥架」。

事前準備　個人目錄已有品項

操作位置　首頁 → 進入我的藥局

成功判準　四層十格。RX 放 OTC 提醒 5 秒，未分類提醒 3 秒。

常見問題與處理　若 WebGL 無法啟用，可用下方按鈕與格位清單。至少須保留一座架。

21. 下載 HTML 成果

目的　完成「下載 HTML 成果」。

事前準備　藥架已完成展示配置

操作位置　3D 藥局總覽

成功判準　成果可獨立開啟，包含已上架品項。

常見問題與處理　手機若以檔案預覽開啟，改由支援本機 HTML 的瀏覽器處理。

22. 重新開始

目的　完成「重新開始」。

事前準備　檢查是否需先下載成果

操作位置　3D 藥局總覽

成功判準　本次使用端資料清空，已下載成果仍可開啟。

常見問題與處理　重整也會清空。請在重置前核對是否已下載成果。

23. 故障排除

目的　完成「故障排除」。

事前準備　記下網址、操作步驟及錯誤訊息

操作位置　瀏覽器 / Actions 工作紀錄

成功判準　能指出出錯的步驟與受影響的範圍。

常見問題與處理　求助時可提供錯誤畫面，先遮蔽任何個資或憑證。

24. 日常維護

目的　完成「日常維護」。

事前準備　準備獨立分支及正版素材

操作位置　docs、public/teaching 和 GitHub Pull requests

成功判準　測試通過，原有教材檔案仍完整，封面來源可追溯。

常見問題與處理　若測試資料混入正式索引，在發布前移出並重新驗證。

25. 安全地請 AI 協助

目的　完成「安全地請 AI 協助」。

事前準備　備妥可公開的重現資訊

操作位置　AI 對話與 Pull Request

成功判準　每項變更有可重現的查核結果。

常見問題與處理　AI 未取得畫面或工具輸出時，請它清楚標示未驗證項目。

請按 Ctrl+C（Mac 按 ⌘C），或長按選取後複製。
